# PRODUCT.md

**BrainOS – AI Knowledge Operating System**

---

# Product Overview

BrainOS is an **AI-powered knowledge operating system** designed to capture, connect, and surface insights from a user's personal knowledge.

The system transforms scattered notes, ideas, and experiences into a **living knowledge graph** that continuously generates insights.

BrainOS is inspired by the philosophy behind Obsidian but extends it with **AI reasoning and automated insight discovery**.

The goal is not simply to store information, but to help users **notice patterns and hidden knowledge** they would otherwise miss.

BrainOS aims to become a **true second brain** for its users.

---

# Product Ambition

BrainOS is built with the ambition to become a **$100M+ product** by solving a fundamental problem:

> Humans accumulate knowledge but rarely rediscover its hidden value.

BrainOS aims to become the **AI layer for human thinking**.

---

# Core Product Philosophy

### Knowledge Should Compound

Each piece of knowledge should increase the value of the entire system.

The more users write, the smarter BrainOS becomes.

---

### Capture Should Be Frictionless

Ideas appear quickly and disappear quickly.

BrainOS must allow users to capture ideas **within seconds**.

Multiple input channels exist to support this:

* Web UI
* Messaging interface
* API integrations

---

### Insight Is the Real Value

Most note apps focus on storage.

BrainOS focuses on **pattern discovery and insight generation**.

The system should regularly produce moments where the user thinks:

> "I didn't realize these ideas were connected."

---

### Surprise Is a Feature

The product should surface **unexpected but valuable connections**.

Insight generation should feel **serendipitous but relevant**.

# Product Interface

## Web Application (Primary Interface)

The primary interface is a **web application** where users can:

* write notes
* organize spaces
* view their knowledge graph
* explore insights
* retrieve connected knowledge

Main interface components include:

### Notes System

Users create structured notes.

Notes can include:

* text
* tags
* entities
* links to other notes

Notes are organized by:

* spaces (life, work, etc.)
* tags
* time

---

### Knowledge Graph

The knowledge graph visualizes relationships between:

* notes
* entities
* concepts
* tags

The graph allows users to:

* discover related knowledge
* explore clusters of ideas
* identify important nodes

---

### AI Assistant

The AI assistant helps users:

* retrieve knowledge
* summarize topics
* generate insights
* identify connections

The assistant operates on the user's **entire knowledge graph**.

# Extended Input Channels

## Telegram Integration

BrainOS integrates with Telegram as a **fast capture and retrieval channel**.

Telegram is not the main product interface but acts as a **knowledge gateway**.

Users can:

Capture quick ideas

Example:

```
note: AI agents could coordinate software development tasks
```

Retrieve knowledge

Example:

```
what did I write about SSO?
```

Generate insights

Example:

```
insight: startup ideas
```

This allows users to interact with BrainOS **anywhere without opening the web app**.

# Core Features

## Knowledge Capture

Users store ideas quickly.

Sources include:

* typed notes
* meeting notes
* quick thoughts
* research links

The system automatically extracts:

* entities
* concepts
* relationships

---

## Knowledge Linking

Connections between ideas can be:

Explicit
Users manually create links.

Implicit
AI detects relationships between notes.

Example connections:

```
AI Agents → Developer Workflow
SSO → Shopify Authentication
Knowledge Graph → Insight Engine
```

---

## Knowledge Graph

All stored information becomes part of a **graph structure**.

Nodes represent:

* ideas
* notes
* people
* companies
* concepts

Edges represent:

* relationships
* references
* similarity

This structure enables deeper reasoning and discovery.

---

## Insight Engine

The system periodically analyzes the knowledge graph and surfaces insights such as:

* repeated themes
* emerging interests
* hidden relationships
* potential opportunities

Example insight:

> "You have written about AI agents, developer workflow automation, and Telegram integrations multiple times. This may indicate an opportunity to build AI tools for developer productivity."

---

## Knowledge Retrieval

Users can ask questions about their own knowledge.

Examples:

```
What did I say about SSO?
```

```
Summarize my notes about AI agents.
```

The system returns:

* relevant notes
* connected concepts
* related insights
