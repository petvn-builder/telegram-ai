# Calm AI Notebook — Complete UI Redesign Specification

## 1. Product Philosophy

This product is not a SaaS dashboard.
It is not a productivity weapon.
It is not a futuristic sci-fi interface.

It is a calm, intelligent notebook where thinking feels effortless and AI gently supports cognition.

The emotional goals:
- Quiet
- Spacious
- Focused
- Intelligent but non-intrusive
- Book-like readability
- Zero visual anxiety

AI is a supportive layer, not the main character.

---

## 2. Global Visual System

### Background
Primary background: warm neutral
- #FAFAF8 or equivalent soft paper tone
Alternative: #F5F5F4 (stone-50 range)

No gradients.
No glow.
No dramatic contrast.

The interface should feel like modern digital paper.

---

### Typography

Base font size: 16–18px  
Line height: 1.6–1.75  

Typography must feel like reading a book, not using a dashboard.

Hierarchy:
- H1: Strong weight, generous spacing above
- H2: Clear but not oversized
- Body: Highly readable
- Secondary text: soft gray (#6B7280 range)

No condensed layouts.
No tiny SaaS fonts.

---

### Color Tokens

Primary text: #111111 or softened near-black  
Secondary text: neutral gray (#6B7280 range)  
Borders: #E5E7EB (very light)  
Accent (AI only): soft muted blue or lavender (desaturated, calm)

Accent color must never dominate the interface.

Use color sparingly.

---

### Borders & Radius

Border radius: 12–16px consistently  
Borders: 1px very light neutral  
Shadows: extremely subtle, almost invisible  

No heavy cards.
No thick outlines.
No visual clutter.

---

## 3. Layout Philosophy

The note content is the center of gravity.

### Structure

Left: Minimal sidebar
- Soft background contrast
- No harsh dividers
- Minimal icons
- Generous spacing

Center: Main note canvas
- Wide reading width (comfortable line length)
- Large breathing space
- Clear content hierarchy

Right (optional): AI assistant panel
- Collapsible
- Subtle visual separation
- Never visually louder than the note

No dashboard grid.
No widget-heavy layout.
No aggressive card stacking.

---

## 4. Spacing System

Use consistent spacing scale:

4 / 8 / 12 / 16 / 24 / 32 / 48

Prefer 24–32 for section separation.

White space is a feature, not wasted space.

---

## 5. Interaction Principles

All motion must feel calm.

Transition duration: 150–200ms  
Easing: ease-in-out  
No bounce.
No exaggerated scaling.
No flashy animation.

Hover states:
- Subtle background shift
- Very light elevation if needed

Focus states:
- Soft outline or gentle background tint
- Never bright glowing rings

---

## 6. AI Integration Principles

AI must feel ambient and contextual.

Avoid:
- Large chatbot boxes dominating layout
- Loud AI branding
- Flashing suggestion panels

Instead:

- Highlight text → small “Ask AI” bubble appears
- Inline summaries appear softly under headings
- Suggestion chips appear subtly after pause
- AI panel slides in quietly when invoked

AI should feel like a thoughtful assistant sitting beside you.

Not a tool demanding attention.

---

## 7. What Must Be Removed

Remove:
- Heavy card-based dashboard styling
- Strong drop shadows
- Bright saturated accent buttons
- Thick separators
- Dense information packing
- Overuse of icons
- Visual noise

If something feels energetic, reduce it.

If something feels crowded, remove it.

---

## 8. Emotional Validation Checklist

Before finalizing the redesign, verify:

- Does the UI feel slower and calmer?
- Is the note content clearly the focus?
- Does AI feel supportive rather than dominant?
- Is there generous breathing room?
- Would someone enjoy reading here for an hour?

If not, simplify further.

---

## 9. Implementation Instruction

You are allowed to:
- Break existing layout structure
- Remove components entirely
- Rebuild the layout hierarchy
- Replace current color system
- Refactor spacing globally

Treat the current UI as a prototype.

Rebuild the interface fully aligned with this Calm AI Notebook system.
